# Typography and asset browsing

Forma's graphics editor offers 13 curated families: five system faces and eight self-hosted open-source Google Fonts (Inter, Roboto, DM Sans, Manrope, Plus Jakarta Sans, Space Grotesk, Playfair Display, Lora). The variable font files are version-locked through Fontsource packages and served by the app. Selecting a font does not require a Google API key or a network request to Google. The live Google Fonts metadata API could offer a much larger catalog, but it requires an API key and would make asset management and export behavior harder to guarantee. [Google's CSS API](https://developers.google.com/fonts/docs/css2) supports variable weights; [its metadata API](https://developers.google.com/fonts/docs/developer_api) requires an API key. [Fontsource](https://fontsource.org/docs/getting-started/install) supplies the self-hosted files used here.

Select a text object to use the compact toolbar for family, size, weight, color, bold, italic, underline, strikethrough, alignment, letter spacing, line height and opacity. The Text inspector offers the same detailed settings. All typography values are stored on the selected layout; applying a new manuscript keeps those styles and changes only the approved wording. Invalid imported values are rejected by project validation. Graphics SVG export embeds only the selected self-hosted font files, so it does not depend on the viewer having those fonts installed; PNG/PDF graphics export uses that SVG path. Editable Forma files retain font family and style values.

The font bundles currently contain Latin subsets. Other scripts may use the system fallback, and generated PDFs/PPTX for documents and slides have separate rendering adapters. Before promising a multilingual or target-app-perfect output, test representative exports in the intended viewer and add the required script subsets to the font catalog.

The Elements drawer has functional categories rather than a generic stock library: Shapes shows the supported shape kit, Images opens uploads, Text opens editable text boxes, Tables opens the Document tool, and Charts opens Slides. Design also exposes Graphics, Reports and Slides format entry points. Starting a Graphic from a report or deck saves the source as a separate project and carries its manuscript into the new graphic. Frames, animations, stock media and AI element generation shown in the Canva reference are not implemented in Forma; they should appear only when backed by real editor and export behavior.

Implementation entry points: `src/domain/design/fonts.ts` defines the catalog; `src/styles/fonts.css` registers local files; `src/features/editor/components/EditorTextToolbar.tsx` and `SelectionInspector.tsx` edit typography; `src/features/editor/lib/fontAssets.ts` embeds export fonts; `src/features/editor/panels/EditorLayerPanels.tsx` defines Elements categories. Add a family in all three catalog/assets/styles locations, then verify the editor preview, editable backup and SVG/PNG output.
